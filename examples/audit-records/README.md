# Sample Audit Records

These sanitized sample records demonstrate the three integrity states
produced by the Digital Evidence Locker:

- `original.json` — first observation of a file
- `unchanged.json` — the same file content detected again
- `modified.json` — previously recorded file content has changed

The examples mirror the audit-record structure generated by the Lambda
function but use sanitized local test data.

They are provided for demonstration and documentation purposes and are
not exports from the original AWS Academy sandbox environment.
